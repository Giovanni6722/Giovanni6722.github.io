ABOUT_ME

I'm studying Computer Science with a focus on the parts of the field most people skip over — operating systems, low-level systems programming, synchronization, memory, and the mechanics that live beneath the abstraction. I find this stuff genuinely interesting, not just academically useful.

My coursework spans algorithm design, concurrent programming in C, Java application development, and UX design. I work with Java, C, C#, Python, PHP, HTML, and React depending on what the project calls for, and I'm comfortable with tools like GDB, VIM, EMON, Git, Maven, and Unity.

On the side I'm building Hooked — a 2D metroidvania in Unity where the core traversal mechanic is a physics-based grappling hook. It's the biggest personal project I've taken on and it's teaching me things coursework can't.

I work well in teams and independently. I've collaborated on a full Java business management application with other contributors, managing version control, branch workflows, and code review through GitHub. I take ownership of what I build.

PROJECTS

HOOKED
2024 – PRESENT

A 2D metroidvania built from scratch in Unity. The entire traversal system is designed around a physics-based grappling hook — every movement decision the player makes runs through it. Uses raycasting, DistanceJoint2D physics, and launch velocity calculations to feel responsive and weightful at the same time.

Set in a post-apocalyptic steampunk world with a story built around themes of loss and the act of reaching for something that might not be there. Core mechanic is functional; the world is being built around it.
